# 旧版答辩文件

本目录保存 v4–v8 的五份 PPTX、对应的一次性构建脚本、早期 `opening_ppt.md`、旧版 QA 与
v6 设计稿，共 16 份原有文件。它们包含当时的人工版式和逐页检查，均按原字节从
`opening/slides/` 移来；移动后与 `d32366de` 中同名原路径的 Git blob 核对一致。

这些文件只用于追溯当时版本。旧脚本内的相对路径按原目录编写，如需原样复现，先从
`d32366de` 恢复 `opening/slides/` 下的原路径。最近一版幻灯片入口、学校模板和再次使用前的
检查要求见[上级说明](../README.md)；旧版 QA 不代表最近一版的内容状态。
