# 开题 PPT 制作专项检查清单

> 本文件不是独立规则源。实际创建、编辑或导出 PPT 时，在根 `AGENTS.md`、`opening/AGENTS.md` 和
> `figures/AGENTS.md` 之后读取；只修改报告或文献时无需加载。当前 PPT 状态见 `slides/README.md`。

## 1. 模板与安全区

- 学校模板提供母版、占位符、主题字体、校徽、页眉页脚和安全内容区，不作为整页截图背景。
- 复用模板已有元素，不重复绘制；正文、图表和流程图不得压住页眉、页脚或校徽。
- 用户已手动调整现有 PPTX 时，只做 shape 级增量修改，不运行全量 builder 覆盖。

## 2. 页面信息

- 每页只有一个主结论；标题说明该页回答的问题或观察。
- 页面使用关键词、短句和必要数字；详细因果、限制和回答方式进入备注。
- 表格只保留汇报所需列并给出结论句；内容过密时拆页或改用更合适的图，不缩成不可读小字。
- 每页备注包含 `汇报讲稿` 与 `答辩备注`，讲稿不逐字重复页面。
- 可见文字按根“文档受众与对外表达”规则检查，系统名、数据结构和指标首次出现时说明作用。

## 3. 图表

- 实验数据图从 `figures/data/report_main/` 或 `figures/data/backup/` 引用，不在 PPT 目录维护副本。
- 使用 `figures/` 中已审计的 PNG/SVG；不手工重画数据、不拉伸低清截图。
- 图表包含图题、轴/表头、单位、图例和必要限制；备注说明数据来源、读法与不能推出的结论。
- 流程图中的组件、箭头、颜色和术语遵循 `figures/AGENTS.md`，不为 PPT 单独创造另一套视觉语义。

## 4. 生成与增量修改

- 新建 deck 优先使用母版/占位符；已有 deck 优先增量修改对应 shape。
- 修改前记录目标 slide/shape，修改后确认没有改变用户未授权的尺寸、位置、字体和备注。
- PPTX、Markdown 源稿和生成脚本的角色写清；若 PPTX 含人工调整，不把重新生成脚本称为唯一源。

## 5. 完成检查

导出后必须在 WPS 或 PowerPoint 中实际打开，并逐页检查：

- 标题、模板元素和安全区；
- 字体替换、文本溢出、表格跨页和图像清晰度；
- 颜色、图例、箭头和缩放后的可读性；
- 备注是否存在且与页面一致；
- 报告、PPT、飞书中的题目、研究内容、数字和限制是否一致。

无法实际打开或读回时，状态写 `pending visual verification`，不声称 PPT 已完成。
