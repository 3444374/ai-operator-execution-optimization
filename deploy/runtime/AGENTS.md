# deploy/runtime/AGENTS.md

继承上级规则。运行流程、能力组和配置示例见 [README.md](README.md)。

- machine profile 描述可验证能力，不保存实验最优参数；默认按观测硬件选择，显式 `--machine-profile` 覆盖须在报告注明。
- 每台机器使用独立的仓库外 runtime env，示例仅用占位符；性能校准、依赖隔离和隐私按根 §5、§8 执行。
- `assets.json` 只声明可信来源、目标与完整性要求；受许可资产使用 `manual`，缺少许可时停止自动获取。
- `check` 默认只读；安装、下载、导入保持独立显式动作，不自动安装驱动/CUDA。
- 新增能力/资产时核对来源、目标路径与完整性并更新受影响入口；解析、校验或安装行为变化需对应测试，
  纯元数据修改复用已有校验。下载成功不代表 workload 正确。
