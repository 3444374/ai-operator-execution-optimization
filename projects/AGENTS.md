# projects/AGENTS.md

本文件继承根 `AGENTS.md`，只增加旧 PPT 生成工程的归档规则。本目录不是当前工作目录或研究
材料入口，当前内容见 `README.md`。

## 作用

- 保留 2026-07-12 开题答辩 PPT 的模板分析、内容填充、版式修复、导出和验证记录。
- 只用于复现历史产物或参考工具链经验；新的开题材料不在这里生成。

## 内容说明

`opening_defense_20260712/` 是 2026-07-12 开题答辩 PPT 的生成项目：

- `analysis/`：学校 PPT 模板结构解析、填充计划生成。
- `validation/`：生成后 PPT 的版式检查、边界审计、内容读回验证。
- `exports/`：生成的 PPTX 导出文件。

## 边界

- 不存放正式实验数据、结果报告、学习材料或项目规则。
- PPT 的最终正式版本放在 `opening/slides/`，不在这里。
- 图资产放在 `figures/`，不在这里复制。
- 本目录的工具脚本和中间文件不作为项目文档入口。

## 规则

- 默认不修改本目录。确需复现历史产物时，必须跑 `validation/` 中的检查脚本。
- 新 PPT 内容以 `opening/report/opening_report.md` 和 `figures/` 为依据，并在 `opening/`
  的当前工具链中实现。
- 不把本目录中的旧 PPTX 当作当前版本，也不在一般清理中删除历史输入、输出或验证记录。
