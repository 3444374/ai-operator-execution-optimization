## 本轮小规模真实验证（2026-09-20）

用户已要求进行 M1、M2、F 真实测试。本节记录实施者在执行前限定的具体范围；
目标是得到当前路径的真实执行和数值/资源证据，不把短查询自动登记为稳态方法结论。
只使用已核对的 AutoDL、现有公开模型与数据，独立 PG18.3 数据目录和自有进程；每次只用一张 GPU。
当前软件为 vLLM 0.25.1、Ray 2.56.1；driver 与 vLLM 环境分开。无新增模型或数据下载。

### 固定输入与上限

- 文本：Qwen2.5-7B-Instruct，revision `a09a35458c702b33eeacc393d103063234e8bc28`，
  BF16、TP1、context4096、max-num-seqs128、batched-token8192、FCFS、分块输入处理；前缀缓存关闭。
  沿用 Movie-derived Map 的固定二值分类语义、temperature0、最大输出128。单张4090，服务显存比例0.8。
- 输入从此前按电影划分的 512/1024 行中分别取前128/256行，正确性用调参组前8行，保留来源与新 manifest SHA。
  不按标签或预测选择，不扩大输出上限制造长输出。调参 work174–251，评价175–248，仍是近同质短评论。
- 全部文本最多 **17,000 次 POST、60 分钟**，包含预热、正确性、启动/核验及清理；下面完整分支最多16,952次。
  各阶段用独立新账本及明确单元，不将未执行阶段的余额转给额外点。
- 图像：同一 CLIP ViT-B/32 模型与 processor，revision `3d74acf9a28c67741b2f4f2ea7635f0aaf6f0268`，
  模型算术 float32、输入224、投影后512维、L2归一化，关闭 TF32。只从已核验文件构造本地 revision 缓存。
  COCO val2017 文件名顺序中选前12张满足既有编码字节/像素要求的图像，加2个重复 occurrence 与1个 NULL。
  每张最多256 KiB，不改变图像原始编码；3张超字节候选记录排除理由。
  单张4090，最多 **160 次模型前向、20 分钟**，计划正常及预定异常操作共151次。

### M1 的条件阶段

所有扫描点统一 L128、Core 输入/结果各128 MiB、PG 留存256 MiB/暂存4 MiB；
先按 v2 预检证明可达，再观察实际供给。CPU/模型/服务参数不随 C 变化。
每轮除预热外都保留配对原值：`epsilon=0.03`、相对极差上限0.10；
固定查询中间60%用于供给解释，其中至少80%的时间 HTTP 活跃数须达到 `ceil(0.9*C)`。
主指标仍使用完整调用至 EOF；这些数值用于保守小规模筛查，不是等效检验或 GPU 满载要求。

| 阶段 | 预定单元 | 最大 POST / 阶段时间 |
|---|---|---:|
| 正确性 | PG/direct 各8行 | 16 / 120秒 |
| 容量筛查 | C4/16/64 × PG/direct，各128行，1预热+3测量 | 3,072 / 540秒 |
| 工作量调参，只有 PG 有平台候选才执行 | 调优请求数、C64请求数（相同时不重复）、C64下W4096/8192/262144，128行，1+3轮 | 2,560 / 480秒 |
| 独立评价 | 调优请求数、C64请求数、C64且W262144表征控制、合格的调优W；相同组只保留一次，256行，1+3轮 | 4,096 / 600秒 |
| 代表性观测开销 | 选定请求数C的full/compact，256行，1+3轮 | 2,048 / 360秒 |

W262144 等于64×context4096，对支持的请求不生效；不借用评价输出选 W。
调参W须实际出现工作量阻塞且各配对吞吐比满足声明差异，才进入独立评价；没有合格W就保留负结果。
筛查没有平台候选或重复波动大时，停止后续 M1 阶段，不扩大 C、换输入、改阈值或自动追加重复。
匹配 direct 仍包含 PG 源读取/客户端准备，不能把两路径耗时相减当纯 PG 开销。

### M2 的首次真实实验层对照

当前 SemMap carrier 不接受这条全局预扫/重排 SQL 形状，本轮不改 grammar、PG planner 或生产责任表。
五组均通过**同一 PG 源事务＋已有 DirectMap 有界客户端**执行，身份为 `direct_client_control`；
这验证信息策略及其真实代价，不冒充已经接入 SemMap 的新物理路径或原生系统 baseline。

- 五组：逐行 FIFO、同窗口同信息 FIFO、窗口长度次序、付费全局 ID/work/digest 规划、复用已付费全局元数据。
  本地排序复用 `WorkWindowOrganizer`；全局元数据用有限 SQLite 文件及其排序索引，不留存全体 prompt。
- 共享同一不可变 PG 表、repeatable-read 只读快照、模型请求语义与结果目标；全局执行重新读取 payload 并逐行核对摘要。
  所有组使用同一有界磁盘结果存储恢复原始行序，构建、写入、读取及最终消费均在完整查询计时内。
- C采用M1调参选点；若没有平台候选，固定C4，仅登记真实功能与信息成本诊断，不称强静态性能结论。
  候选窗口64，候选payload预算16 MiB、元数据主文件4 MiB、结果主文件64 MiB；
  另报C个HTTP响应预留、SQLite缓存/日志及实际进程内存，文件页上限不称整个进程RSS上限。
- 先做五组各8行正确性，共40次；再在固定256行评价上五组各1预热+3测量，共5,120次。
  阶段分别120/720秒。首次全局元数据构建计入其查询；复用组必须引用已记录的生产者与文件SHA，
  不免费混入首次构建结果，也不把一次性构建成本隐去。
- 标签只评价；完整行/请求关联、每次结果变化、质量、JCT、CPU、读取/分词/排序、元数据与payload留存都保存。
  三次同生命周期重复不足以宣布一般性优越或等效；无收益同样报告。

### F 的真实 CLIP 核对

独立同步 reference、PG reference 和 PG staged 各2张预热＋3轮14个非NULL occurrence，
共132次前向。额外 staged LIMIT1 1次、INSERT/ROLLBACK 14次、已完成前向后的受控错误与恢复2次、
前向完成但结果尚未交付时的取消与恢复2次，总计151次；NULL、LIMIT0和非法编码不进入模型。
本轮不注入硬件 CUDA 故障，也不声称已验证计算中的 GPU 抢占。

数值条件预先固定：逐维 `rtol=1e-5, atol=1e-6`，L2范数误差≤1e-5；一维512个有限float4、行关联、重复输入及NULL一致。
staged 复用 MethodDriver、阶段资源与 Ray actor，CPU prepare/model 各1项，两个阶段合计最多2个图像请求，
PG每查询窗口2；共享服务总体留存4行、两Job独立存储。actor任务不重试/重启。
取消请求不立即释放张量或任务；等待actor完成后释放，随后同一worker继续服务。

### 停止、记录与清理

任何非预期模型/关联/输出格式/资源/期限失败停止对应真实试验，不自动重跑、退款、重置额度或放宽数值条件。
前述预定错误与取消必须得到预期结果并确认清理，否则也停止。合法但语义答错保留在质量分母。
已有受控演练通过后才启动本轮真实模型；受控准备失败另保留，没有消耗真实额度。
原始输入、模型输出与完整事件放私有目录；公开报告仅导出脱敏配置、计数、指标、失败与摘要。
文本实际POST账本与服务日志独立核对，图像前向在模型调用前计数；同步保存服务running/waiting、GPU与进程采样。
结束停止自有模型、PG、Ray及子进程，检查占用和端口，恢复临时ACL，原始证据不删除。
