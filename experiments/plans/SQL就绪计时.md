# 数据就绪后的 SQL 与原生 API 计时

本方案补充已有完整应用比较，回答原始数据、连接和可复用运行组件已准备时，提交查询到统一消费端
读完结果需要多久。旧应用计时和失败证据保留；本次不从旧数值减去准备成本推算新结果。
本页保存实施要求，实际运行、失败与整合验证见[结果报告](../results/postgresql/query_ready_timing_20261008/README.md)。

## 实现与观测

- PostgreSQL 连接、输入表、语义配置和网关进程先准备；实际 `cursor.stream` 入口开始查询计时。
- DuckDB 社区 AI 保持已加载扩展的连接和原始影评表；SELECT 内形成原有提示并调用 `ai_try_complete`。
- Sema 使用同一作者二进制的持续 SQL 会话，先完成 SET、建表和 COPY 并确认输入数量，再提交原生语义 SELECT。
  每条语句最后的普通 SQL 标记确认消费完成，标记开销计入查询时间；不修改二进制和语义解析。
- LOTUS 先准备 tokenizer、模型配置和原始 DataFrame；计时内执行原生 `sem_map`。
- Daft 先准备 Native runner、provider 与原始 DataFrame；计时内用原生表达式形成提示并执行 `prompt` 查询图。
- 查询特有的提示装配、work 估算、组织、模型调用和结果消费保持执行归属。准备段不得调用模型。

各路径分别记录准备入口、运行组件就绪、SQL／API 入口、首行、末行、统一消费端 EOF、记录写盘和资源清理。
查询耗时为 `(t_query_terminal_ns-t_submit_ns)/1e9`，完整应用耗时仍由准备入口到同一 EOF 计算。
旧 `t_release_ns` 保留原含义，不当作通用 SQL 提交时刻。

查询超时停止后续模型转发；Sema 还直接取消自有进程。LOTUS／Daft 等没有安全中断接口时，
SDK 请求超时与调用方的140秒单元进程监督处理已有在途调用，不把120秒查询计时器称为原生硬中断。
HTTP 首错按统一观察触发取消；Sema 在错误情况下会尝试原生重复提交，代理不继续转发，保留尝试和错误记录。

所有路径使用同一只做转发的 HTTP 观察代理，记录收到请求、读完请求体、计账回调、上游发送、读完上游响应、
代理响应写完和错误。使用单调时钟，墙钟仅保留兼容字段。PG 仍在已有 guard 中计账，代理不重复计数；
原生系统仍在代理发送前计账。代理收到请求至本地响应写完是统一 HTTP 区间，不包含 SDK 前排队与客户端接收、解析。
批量单行交付另从实际查询入口到该行被消费计算，不称为独立在线请求到达延迟。

## 验证与真实模型预演

先验证准备阶段零调用、重复值与行身份、提示字节、原生算子、完整结果、超时／错误／取消及资源清理。
本机或服务器 CPU fixture 不调用真实模型；失败输出保留。原接口与默认应用计时仍通过相关既有测试。

真实预演沿用指定服务器 GPU0、缓存 Qwen2.5-7B-Instruct 与独立 driver／vLLM 环境。先保存只读环境报告，
确认旧实验进程结束、GPU0 空闲、端口可用、输入和模型校验值，使用独立数据盘目录和新运行标识。
本次新增观察代理后重新做正确性与规模检查，参数在测量中保持。

| 路径 | 请求数配置 | 工作量额度 | 原生执行设置 |
|---|---:|---:|---|
| PG＋SemLoom 本地 HTTP | 16 | 按请求数 | PG 语义 Map；内部参照 |
| LOTUS Map | 16 | 原生所有权 | LOTUS1.2.4，缓存与重试关闭 |
| DuckDB 社区 AI | 64 | 原生所有权 | DuckDB1.5.4／ai0.4.14，缓存与重试关闭 |

每路径先16行正确性、128行规模检查、512行预热，再做10次512行测量；八路径最多46,208次真实调用，
总时长最多30分钟，包含最后120秒清理。测量轮次旋转路径顺序，使用完整相同输入；每次独立准备并保留准备成本。
首次请求、行关联、资源、语义检查或服务错误即停止，不自动重跑、不退款；修复后另记新计划与运行身份。
模型服务启动和事后准确率核对单列，generation 上限128、temperature=0、prefix cache 关闭。

## 能说明什么

输出包含完整应用与就绪后查询的全部重复值、准确率、实际 HTTP 峰值、输入／输出 tokens、行与独立查询样本数。
分别统计完整查询、批量单行交付和统一 HTTP 区间的样本 P99／P99.99，说明计算式和观测范围。
每路径10条查询时，两种完整查询分位均只是样本最大值，不能说明可靠的总体 P99.99，也不作调度优势结论。
提示、解析、token 工作和原生并发仍不同，数据就绪只能排除装载与可复用初始化；SemLoom Daft／Ray 主执行路径未纳入。
