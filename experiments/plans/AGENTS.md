# experiments/plans/AGENTS.md

本文件继承根 `AGENTS.md` 与 `experiments/AGENTS.md`，只增加实验计划的状态和归档规则。

## 内容

每个实验计划需包含：研究问题、对应研究内容、baseline、变量、消融设置、评价指标。

## 状态分层

- 顶层 `*.md`：仍有待执行项或持续维护的当前计划；必须在文件开头写当前状态、已完成项和
  剩余项。
- `completed/`：计划中的主要运行或门禁已经完成；文件保留原合同，开头必须指向结果目录。
- `reference/`：长期检查清单、baseline 规则和设计方法；不直接表示某个实验待运行。
- `archive/`：已被当前方向替代、暂停且无当前执行授权的历史方案。

已完成计划不得继续留在顶层制造“待执行”错觉。一个计划若同时有已完成和待完成部分，应把
剩余工作收敛成明确、可执行的小节；若剩余内容已由另一当前计划承担，则整份移入
`completed/` 并指向替代入口。

移动文件时必须更新全仓引用，并运行 Markdown 本地链接检查。历史结果 README 中记录的旧命令
可以保留，但必须能从当前索引找到新位置。
