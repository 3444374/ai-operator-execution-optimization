## 上下文配置的后续独立变化

源码审计确认普通异步records缺省仍显式传 `max_model_len=4096`、
`gpu_memory_utilization=0.8` 与 `dtype=bfloat16`。本次模块提取不改变这些值。
用户另要求未显式给上下文时由vLLM解析；该项需在ready后取得实际`ModelConfig.max_model_len`，
再向上游校验、可选token工作量及身份传递。缺失实际值不能解释成无限，也不能留下4096影子限制。
显式上下文、同步参照、历史参数、单GPU及张量／流水线并行各为1的支持范围与有限资源保护分别核对。
每轮token由另一个独立候选处理；显存比例与dtype的默认不在该上下文切片内改变。

本轮真实Ray、模型及GPU运行均为0。完整查询耗时、质量与实际配置读回仍须由专用测试会话
在最终已审准确源码上比较，不能从配置提取或CPU耗时推断加速。

## 异步模型上下文的 CPU 候选

该切片基于上述 b018 配置提取提交，与结构整理分别审阅。`EngineSpec.max_model_len` 未指定／null 时，
异步 `AsyncEngineArgs` 真正省略这个关键字；显式正整数精确传入，0、负数、布尔值和字符串仍拒绝。
在原单模型实例的 ready 回执读取已构造的 `vllm_config.model_config.max_model_len`，
记录请求值、实际值、引擎身份、配置摘要与观测内容摘要；委托模式缺失、非法或错实例的回执均拒绝，原生ready同时核对显式值与实际值。
显式有限值仍可用于启动前检查，旧式显式接口没有观测时保留声明值检查，不把声明值记成实际观测。
采用依据为固定 vLLM v0.25.1 的[AsyncLLM 实例配置](https://raw.githubusercontent.com/vllm-project/vllm/v0.25.1/vllm/v1/engine/async_llm.py)
与[模型配置](https://raw.githubusercontent.com/vllm-project/vllm/v0.25.1/vllm/config/model.py)，本轮没有加载真实模型。

数据沿原 ready 通信返回。通信提交侧、异步生成侧、应用 token 组织及可选在途工作量分别使用解析值，
未知长度不作无限；没有保留4096作为异步影子上限。原生完整渲染后仍检查提示 token 数加输出上限，
超限在调用模型生成前返回已确认失败，不截断、拆分或自动缩短生成参数。
可选工作量描述与 live admission cache（已启动模型的接纳策略缓存）绑定该实际值；
不同解析长度不共用身份，实例标识本身不使可兼容缓存无谓分叉。

普通带缓存的冷查询先沿既有 owner 取得 ready，原 source／方法／环境预检先执行，
实际就绪耗时记录为 `model_context_startup_seconds` 并计入 `query_seconds`，不能再次相加；
外围 `entry_work_wall_s` 继续覆盖身份绑定、缓存和查询返回。失败没有查询时间时保留原失败，不制造零耗时。
空查询不为缓存启动模型；常驻 Session 使用原 owner 已有回执，不新增模型或采样器。

同步 SemLoom 参照、LOTUS／Ray／Daft 的有限同步与 HTTP 参照继续使用原4096缺省及显式值；
数据精度、0.8显存比例、原生序列兼容默认、单 GPU 支持、方法语义、资源保护和历史显式配置保持。
Kalypso 未修改。新旧性能比较须匹配实际模型、上下文及其他执行参数，不能直接套用旧实验数值。

CPU 验证按方法与最后有效回执去重：选择404个方法，其中400个有方法级结果，
372成功、6个既有失败、22个方法跳过，另1个类的4个方法因缺少固定 SemBench checkout 未运行。
六个失败均在未修改 b018 上独立复现，涵盖提示捕获、取消／晚到回执及在途工作量；原断言未改。
本轮六项选择不是对旧报告计数的改写。早期缺 msgspec、GPU ready fixture 缺构造状态、
空查询 fixture 的目录／返回值准备错误及旧解释器缺 Daft 的记录均保留；
分别复用已有 CPU 环境、补明确合成观测并复测，没有安装依赖或放宽断言。
11项 Daft 同步参照检查全部通过；19项设备身份与固定源码默认编码器检查全部通过，
后者只从已有 CPU codec 环境只读补入 msgspec，不运行完整 vLLM 或 CUDA。
这些项目与总数有重叠，不累加；摘要和原件定位见[`raw/context_checks.json`](raw/context_checks.json)。
