# 增量执行精简与可选Daft/Ray文本路径

2026-09-27。按[执行计划](../../../plans/archive/数据组织历史方案_20260927.md#incremental-multimodal-delivery)，
保留HTTP路径，新增可选Daft Native分批与Ray Core worker执行。PostgreSQL（PG）继续选择输入、拥有快照、关联行结果、
处理查询取消，并将结果返回SQL客户端。本轮没有增加结果写入PG表的工作。
研究对象为 PostgreSQL 内置 AI 语义算子的外部分布式物理执行与调度优化。

本轮是工程诊断与受控接入验证，真实模型调用0次。旧M1持续供给不足、原C64异常根因未确定及方法未选点的结论不变。

## 顺序、发现与保留的修改

1. **测量执行、观测与额度记账成本。** 使用既有PG18.3诊断安装、隔离数据库及固定25毫秒HTTP fixture。
   先测试512行、C64、完整事件，随后改变一个因素。剖析只覆盖网关的两条PG查询，共1024行；
   `SessionCapacity.usage`调用61,813次，每次以多个生成器重复扫描任务表。profile的累计时间相互重叠，不能相加解释墙钟差额。
2. **精简重复扫描。** 使用一次遍历统计任务、输入、结果与计算预留；全局请求容量已满时直接返回，
   全局工作量放不下某个候选时跳过其局部统计。下一次调用仍重新读任务表，不缓存跨状态变化的计数。
   逐行PG控制消息继续保留；本轮证据支持先处理上述扫描，没有据此认定所有消息往返都能删除。
3. **精简实验记账。** 复用持有路径与预算身份的`CellBudgetLedger`对象。每次预扣仍打开新的SQLite连接，
   在持久事务中检查当前身份、期限、关闭状态与剩余额度。跨进程共享、失败尝试不退款、无自动重试保持原行为。
   把预扣移到独立线程的尝试使PG变慢，已撤回；原补丁和检查日志保留。
4. **接入有限数据批次与可选远端worker。** 已接受的输入窗口由Daft分批，二进制列保留规范请求字节及session/sequence。
   每个批次只放入Ray对象存储一次，worker取得对象引用与行位置；每行HTTP独立完成。
   一个批次最后一条已确认结果到达后才归还对象预留。发送前取消不发出远端请求；发送后继续等待真实结果。
   未确认的远端执行保留资源并使清理报告失败。图像既有CPU准备→GPU对象引用路径继续复用并回归。

## 执行职责与验证范围

- **PG与SQL。** 复用现有v6以及query-job接入，没有改C、SQL语义、PG snapshot或读取连接。
  实际PG测试核对输入/结果摘要、行数与独立绑定；多查询覆盖2/4查询、Filter→Map、空结果、LIMIT、暂停消费、取消与其他查询继续执行。
- **数据与Ray。** Daft 0.7.21、Ray 2.56.1；前者使用Native runner分批，后者使用Core异步actor。
  这是SemLoom管理的可选backend，不能命名为Daft或Ray Data原生baseline。
  核心拥有提交、Job/flow选择和计算额度；异步执行线程拥有Daft窗口及Ray对象。
- **空间。** 核心保留原输入/结果额度；新路径单独记录Arrow对象底层buffer字节，预留早于`ray.put`，释放晚于最后一个成员。
  12–14的数据窗口2MiB、对象额度4MiB；10–11为早期1MiB/2MiB配置。新入口要求窗口至少容纳一个合法协议请求及其行键。
  这些数字不是整个Ray对象存储、所有临时副本、进程RSS或GPU显存的总上限。
- **次数与观测。** Ray路径在远端RPC前调用实验额度检查，不能绕过额度、依赖参数的等号拼写或重复提交。
  远端完成事件保留行键及worker本地耗时；跨节点时钟未对齐，因此HTTP活跃时间线明确标为不可用，不用完成到达时间伪造开始时间。
- **错误与关闭。** 受控检查覆盖同批慢任务、提前/延后取消、预算拒绝、未知结果、对象容量等待、部分actor创建失败及异步backend启动失败。
  原图像路径继续使用现有stage broker；新批次另以中文文本、含PNG签名的二进制字节、重复值、尾批和提前停止消费验证表示；这里不进行图像解码。

12–15启动前记录逐文件SHA；[源码状态](raw/source-states.json.gz)同时保留各中间实现摘要。
10的早期接线没有启动时逐文件清单，不把后来保存的文件状态冒充该次完整源码身份；12–15提供后续带清单的实际验证。
测试环境没有新安装或下载依赖，预检查见[环境记录](raw/environment.json.gz)。C未修改，因此未重跑完整PG编译/TAP。
