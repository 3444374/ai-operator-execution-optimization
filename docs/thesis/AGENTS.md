# docs/thesis/AGENTS.md

继承根规则。材料与发布入口见 [README.md](README.md) 和 [navigation.md](navigation.md)。
跨报告/PPT/飞书/文献的联动修改查 `work_rules.md`；创建、编辑或导出 PPT 查 `ppt_rules.md` 与
`docs/figures/AGENTS.md`；更新文献依据时查 `docs/research/AGENTS.md`。专项材料不能覆盖上级规则。

## 1. 论证与写作

- 开题材料说明问题价值、研究对象、可执行路线与前期依据；初步成果按根 §6 表述，创新点写“预期创新点”。
- 动机按总动机、子问题、证据实验、观察与研究内容组织；实验脚本、参数、对照臂和模块不作为同级研究问题。
- 服务侧状态回答何时提交、发往哪里，Job 状态回答下一份工作来自哪个作业；据此连接提交、路由和多 Job 调度。
- 第一章保留数据库记录、AI operator、外部执行与写回的最小例子，具体实现、参数和实验数字放后文。
- 报告保留研究对象图、两项研究内容的方法图和总体实验方案图；复用 `docs/figures/` 的可编辑源，图题说明
  比较条件和观察，caption 说明读法、来源与结论适用条件。
- 正文用连续论述和过渡组织层次；研究现状解释代表工作的研究问题、方法、实验、限制及与本项目关系，
  对照表只作辅助。进度按多月阶段写目标；学校模板另有要求时以模板为准。

## 2. 文献

- 优先 CCF-A 正式 research paper，再补高相关 CIDR/MLSys/tutorial/benchmark/arXiv、官方文档和源码。
- 题录与版本按 `docs/research/AGENTS.md` 核验；预印本记录 arXiv version，正式版本与本地阅读版本分别记录，
  查询数、数据集、图表及实验数字注明来自哪个版本。
- 开题引用按正文首次出现顺序编号；编号连续、题录一一对应且无未引用条目。
- 文献变化先更新 `docs/research/` 权威材料，再更新开题快照；精读主笔记不由开题快照反向覆盖。

## 3. PPT 与人工编辑保护

- 使用学校模板的母版、占位符、主题字体、页眉页脚和安全内容区，不以整页截图替代模板。
- 每页一个主结论，解释进入备注；备注包含 `汇报讲稿` 与 `答辩备注`。
- 生成或修改 PPT 后，在 WPS/PowerPoint 实际打开，检查溢出、字体替换、图表可读性和备注。
- 用户手动调整过的 PPTX 只做 shape 级增量修改；全量 builder 覆盖仍需明确授权。

## 4. 发布与同步

- 本地 Markdown/可编辑源为权威稿；发布先验证本地稿，再检查实际导出或远端页面，生成/上传不等于 live verified。
- 题目变化同步报告、封面、PPT、飞书标题和根入口；研究内容变化同步技术路线、创新点、进度和答辩备注；
  实验表述变化只更新实际受影响段落与图。报告、PPT、飞书可详略不同，但事实与适用条件一致。
- 飞书文档、Base 和幻灯片按目标类型使用相应连接器/skill；用户提供目标且授权写入后才发布。
- 非实验类修改记入 `logs/project_log.md`；影响结构、方向、结论、入口或项目规则时同时记录根日志。
