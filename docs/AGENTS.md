# docs/AGENTS.md

继承根规则。本目录导航见 [README.md](README.md)。

- 长期知识按主题消化、合并、更新到主题文档；某次测试的全部材料放在根 `results/` 下同一个记录目录。
- 新代码与机制设计进入 `plans/` 的当前任务计划或 `design/` 对应主题；开题/学位材料进 `thesis/`；
  文献与候选方案进 `research/`；一次性材料放 `tmp/`，不进入 Git。
- 已完成的历史设计记录保留在 `design/history/` 原文，文中“当前”“下一步”或旧目录路径均按文件日期读取；
  有效剩余任务迁入当前计划并给出替代入口，按根 §7 更新受影响的索引和日志。
- 沟通带来的修改只落到实际受影响的主题文档，不新建反馈档案；待验证判断不写成已实现或已证明。
- 替代、移动或删除记录按根 §7.1 检查引用、唯一内容和恢复路径，不能仅因过时删除。
