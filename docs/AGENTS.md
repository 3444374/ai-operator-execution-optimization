# docs/AGENTS.md

本文件继承根 `AGENTS.md`，只增加跨目录一次性设计与实施记录的归档规则。当前内容见 `README.md`。

## 边界

- 本目录不是当前项目状态、实验计划或正式材料的权威入口。
- 已完成的设计/实施记录保留原始内容，并在目录 README 标明完成状态和替代入口。
- 新的领域内文档应进入对应目录：代码设计进 `code_doc/`，实验计划进
  `experiments/plans/`，开题正文与规则进 `opening/`。
- 不因文档过时直接删除；先确认替代入口、引用关系和历史价值。纯临时文件应放 `tmp/`，
  不进入 Git。
