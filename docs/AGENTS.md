# docs/AGENTS.md

继承根规则。文档角色与入口见[README.md](README.md)。

- 文献、研究分析与方法依据放`research/`；进入该目录再读其规则。工程接口以源码和代码说明为准，计划与结果分别在`experiments/plans/`和`experiments/results/`维护。
- 讲解按对象进入已有模块、研究文档或结果报告；先核对同主题内容，补充独有说明并引用数据来源。
- 沟通中已确认的内容进入实际方案或事实入口，待核对问题进入对应计划或文献清单；不另存沟通过程、话术或独立记录。
- `archive/`保留有追溯价值的历史工程与开题材料。历史描述按文件日期解释，现行索引指向实际仍维护的入口。
- 移动、替代或删除按根文档生命周期要求核对引用、独有内容与恢复方式。
