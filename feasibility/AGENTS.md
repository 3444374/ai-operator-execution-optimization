# feasibility/AGENTS.md

继承根规则。组件、环境与连接验证入口见 [README.md](README.md)。

- 本目录保存组件 microbenchmark、环境/依赖/连接检查、dry-run 和 smoke；结论只支持组件信号或环境可用性。
- GPU-backed E2E 动机画像进入 `motivation/`，方法效果与正式比较进入 `experiments/`。
- 新验证写明问题、命令、参数、CSV 输出、观察和不能推出的结论；warm-up 按计划排除并保留记录，或单独标注。
- 结果影响课题主线时，原始证据仍留在本目录，在证据台账登记；动机或方法分析引用原始证据，
  不复制为另一份原始结果，也不改变其验证类型。
