## 边界

- 这里的规格和计划用于追溯实现决策，不代表当前实现状态或待执行顺序。
- 当前代码接口、目录结构和运行方式以 `code/README.md`、`code/scripts/README.md` 和源码为准。
- 当前实现/证据状态以 `code/INFRA_STATUS.md` 与
  `experiments/results/EXPERIMENT_EVIDENCE_REGISTRY.md` 为准。
- 历史计划不得覆盖当前实验合同、部署 runbook 或根 `PROJECT_OUTLINE.md`。
- 已完成计划保留原文；若某计划仍有未完成事项，应把有效事项迁入当前领域计划，而不是在
  历史文件中继续追加。

本目录文件变化按根“目录与变更同步”规则更新 README、索引和日志。
