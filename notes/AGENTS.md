# notes/AGENTS.md

本文件继承根 `AGENTS.md`，只增加导师/企业沟通记录和待确认问题规则。当前内容见 `README.md`。

## 作用

- 记录待确认问题、沟通话术和会议结论。
- 把外部反馈及时转化为项目规则、实验计划或方向边界。

## 边界

- 放沟通记录、待确认问题、会议结论和对外话术。
- 不放原始实验数据、正式结果报告、长篇教程或代码实现。

## 规则

对外优先表述为：

> PostgreSQL 内置 AI 语义算子的外部分布式物理执行与调度优化。

Sema 是数据库集成架构参照；LOTUS 是可选兼容 profile、相关系统和完整路径 baseline；Daft、Ray、
vLLM 和其他系统只按其实际角色说明，不写成课题本身。

- 企业侧或导师反馈改变课题边界时，同步检查根规则、README、PROJECT_INDEX 和 `overview/current_direction_and_plan.md`。
- 已解决、过期或被新结论替代的问题要移出当前待办，避免误导后续规划。

详细沟通材料见 `communication_notes.md`。
